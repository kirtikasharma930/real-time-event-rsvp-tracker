# Real-Time Cloud-Based Event Planning & RSVP Tracker

## About the Project
This project is a cloud-based web application designed to simplify event planning and track guest responses in real time.

## Objectives
- Create and manage events.
- Allow guests to submit RSVP responses.
- Track attendees who accept, decline, or are unsure.
- Display updated RSVP counts on a dashboard.
- Store event information securely in the cloud.

## Technologies Used
- Python
- Flask
- HTML, CSS, and JavaScript
- Firebase Authentication
- Cloud Firestore
- Git and GitHub

## Key Features
- User registration and login
- Event creation and management
- Real-time RSVP tracking
- Attendance dashboard
- Cloud-based data storage

Currently under development.
